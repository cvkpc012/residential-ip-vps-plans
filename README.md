## 独享静态住宅IP里，“独享”和“静态”各买的是什么

先拆“静态”。动态住宅 IP 也来自真实家庭宽带，但它会周期性更换，比如每天凌晨自动换一个新 IP。换了 IP，账号绑定的“身份”就在变，平台看到的是同一个账号突然从另一个城市、另一条宽带登录。静态住宅 IP 则是长期固定：从平台角度看，这个 IP 和一个住在当地民房里的普通用户上网没有区别。做长期账号、店铺后台、广告账户，静态是底线，不是加分项。

再拆“住宅”。住宅代理具备 ISP 住宅或移动网络属性，数据中心代理来自服务器机房。前者更适合长期账号和本地化场景，后者更重视速度、并发和成本。但住宅 IP 不等于“住宅代理”这一种形态。ISP 代理的典型做法是：服务器托管在数据中心，但不是使用不属于 ISP 的 IP，而是与提供住宅 IP 地址的 ISP 合作，使用这家 ISP 的自治系统编号（ASN），同时保留高速服务器的速度。LisaHost 的住宅 IP VPS 更彻底一点：住宅段 IP 直接分配给这台 VPS，流量从 VPS 的住宅 IP 出去，中间没有代理转发层。平台看到的连接行为，更接近真实住宅用户，而不是“某个代理服务商转发的流量”。

最后拆“独享”。各家页面上的“独享”承诺口径基本一致：代理使用授权期内 100% 独享；这些代理与住宅 ISP 的固定 IP 地址相关联，并且一次仅供一位用户使用；独享住宅 IP 地址，拒绝重复利用。翻译成买前能核验的话：在授权期内，这条 IP 不与其他用户共享。它不等于“这条 IP 全世界只有你用过”，也不等于“IP 历史清白”。LisaHost 每台 VPS 一个独立 IPv4，不与他人共享这台机器的 IP；但 IP 之前有没有被用过、有没有进过黑名单，官网没有承诺“全新”。买之前用第三方工具查一下 IP 信誉，是更稳的做法。
